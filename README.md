📚 KitapApp — Изучение татарского языка
Кроссплатформенное десктопное приложение для самостоятельного изучения татарского языка

📖 О проекте
KitapApp (тат. "Китап" — книга) — это десктопное приложение для изучения татарского языка. Оно подходит для начинающих и продолжающих пользователей, которые хотят выучить новые слова, освоить грамматику и проверить свои знания с помощью интерактивных упражнений.

✨ Основные возможности

📚 Темы	12 тематических блоков (Семья, Еда, Животные, Цвета и др.)

🃏 Карточки для изучения	Интерактивные карточки с алгоритмом интервальных повторений (SM-2)

📖 Словарь	Поиск, добавление, редактирование слов с примерами

📝 Тесты	Множественный выбор, сопоставление, ввод с клавиатуры

📘 Грамматика	Грамматические правила с примерами 

🎤 Озвучка	Произношение татарских слов через TTS (голос Talgat)

💾 Прогресс	Автоматическое сохранение прогресса и бэкапы

💾 Где хранятся данные

Прогресс изучения (пройденные темы) хранится в:

HKEY_CURRENT_USER\Software\JavaSoft\Prefs\com\tatar\learn (На Windows прогресс сохраняется в реестре по пути:)

~/.java/.userPrefs/com/tatar/learn/ (На Linux и macOS данные хранятся в файловой системе)



Прогресс по словам сохраняется локально в папке .tatar-learn в домашней директории:

ОС	Путь
Windows	C:\Users\Ваше_Имя\.tatar-learn\
Linux	/home/Ваше_Имя/.tatar-learn/
macOS	/Users/Ваше_Имя/.tatar-learn/
Бэкапы автоматически создаются каждый день и при закрытии приложения.

🎶Раздел «Установка зависимостей для озвучки (TTS)»

Windows

Скачайте и установите голос «Татар (Талгат)» с официального сайта RHVoice.

После установки перезапустите приложение.

Linux (Debian/Ubuntu)
Откройте терминал и выполните команды:

bash -> sudo apt update -> sudo apt install rhvoice rhvoice-voice-talgat

macOS
К сожалению, RHVoice официально не поддерживает macOS.
