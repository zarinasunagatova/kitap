**KitapApp** — кроссплатформенное desktop-приложение для самостоятельного изучения татарского языка.

Проект создан как учебное JavaFX-приложение, но доведён до логически завершённой рабочей версии: здесь есть темы, словарь, карточки, тесты, грамматический раздел, озвучка, локальная база данных, сохранение прогресса, бэкапы, логирование и автоматическая сборка готовых приложений через GitHub Actions.

> **Kitap** в переводе с татарского означает **«книга»**.

## 💡 О проекте

KitapApp помогает изучать татарский язык в формате небольшого локального приложения. Пользователь может открывать темы, повторять слова, проходить тесты, читать грамматические материалы и слушать произношение слов.

Приложение не требует сервера и хранит пользовательские данные локально на компьютере. Это значит, что прогресс, словарь, база данных, логи и бэкапы остаются на устройстве пользователя.

Проект хорошо подходит как пример учебного desktop-приложения на Java, где вместе используются:

- графический интерфейс на **JavaFX**;
- локальная база данных **SQLite**;
- работа с JSON-данными;
- озвучка через системный TTS;
- логирование через SLF4J и Logback;
- резервное копирование данных;
- автоматическая сборка desktop-приложения через GitHub Actions.

## ✨ Основные возможности

### 📚 Тематическое изучение слов

В приложении есть тематические блоки для изучения татарской лексики: семья, еда, животные, цвета и другие базовые темы.

Такой формат удобен для начинающих, потому что слова изучаются не случайным списком, а по понятным жизненным категориям.

### 🃏 Карточки для повторения

Для запоминания слов используются карточки. Пользователь видит слово, вспоминает перевод и постепенно закрепляет материал.

В проекте используется идея интервального повторения: слова нужно возвращать в память не один раз, а через определённые промежутки времени.

### 📖 Словарь

В приложении есть словарь, где можно искать, добавлять и редактировать слова.

Для слова можно хранить перевод, примеры и дополнительные данные, которые помогают лучше понять его употребление.

### 📝 Тесты

Приложение поддерживает разные форматы проверки знаний:

- выбор правильного ответа;
- сопоставление слов и переводов;
- ввод ответа с клавиатуры.

Тесты помогают не просто читать слова, а проверять, насколько они действительно запомнились.

### 📘 Грамматика

В отдельном разделе собраны грамматические материалы и примеры.

Этот раздел нужен, чтобы пользователь видел не только отдельные слова, но и правила, по которым строятся фразы.

### 🎤 Озвучка слов

Приложение поддерживает озвучку татарских слов через TTS.

На Windows используется голос **Talgat**, если он установлен в системе. Это помогает не только читать слова, но и слышать примерное произношение.

### 💾 Сохранение прогресса

Приложение сохраняет пользовательский прогресс локально: изученные темы, слова и данные, связанные с обучением.

### 🛟 Резервные копии

В приложении предусмотрены бэкапы данных. Они помогают снизить риск потери прогресса при ошибках, экспериментах или повреждении локальной базы.

### 📝 Логирование

Проект использует логирование через **SLF4J + Logback**. Логи помогают понять, что происходит внутри приложения: запуск, подключение к базе данных, ошибки, создание бэкапов и другие важные события.

## 🚀 Скачать и запустить

Готовые сборки приложения можно публиковать в разделе **Releases**:

👉 [Открыть Releases](https://github.com/zarinasunagatova/kitap/releases)

Если сборка уже опубликована, скачайте архив под вашу операционную систему.

### 🪟 Windows

1. Скачайте архив `KitapApp-Windows.zip`.
2. Полностью распакуйте архив.
3. Откройте папку `KitapApp`.
4. Запустите `KitapApp.exe` или файл `Запустить KitapApp.bat`, если он есть в архиве.

Важно: не запускайте `.exe` прямо из архива и не переносите его отдельно от остальных папок. Рядом с `.exe` должны оставаться папки `app` и `runtime`.

### 🍎 macOS

1. Скачайте архив `KitapApp-macOS.zip`.
2. Распакуйте архив.
3. Откройте `KitapApp.app`.

Если macOS покажет предупреждение о неизвестном разработчике, это нормально для учебного приложения без подписи Apple Developer ID.

### 🐧 Linux

1. Скачайте архив `KitapApp-Linux.tar.gz`.
2. Распакуйте архив.
3. Запустите launcher внутри папки приложения.

Пример:

```bash
./run-kitapapp.sh
```

или:

```bash
./bin/kitap-app
```

## 🎤 Озвучка татарских слов

Для озвучки используется системный TTS.

### Windows

Для корректной озвучки татарских слов рекомендуется установить голос **Talgat** из RHVoice.

После установки голоса перезапустите приложение.

### Linux

На Debian/Ubuntu можно попробовать установить RHVoice и голос Talgat:

```bash
sudo apt update
sudo apt install rhvoice rhvoice-voice-talgat
```

### macOS

На macOS поддержка татарской озвучки может быть ограничена. Если голос Talgat недоступен в системе, озвучка может не работать или работать не так, как на Windows.

## 💾 Где хранятся данные

Приложение хранит пользовательские данные локально на компьютере.

### Основная папка приложения

| Операционная система | Путь |
|---|---|
| Windows | `C:\Users\Ваше_Имя\.tatar-learn\` |
| Linux | `/home/Ваше_Имя/.tatar-learn/` |
| macOS | `/Users/Ваше_Имя/.tatar-learn/` |

В этой папке могут храниться база данных, логи и бэкапы.

### База данных

Основная база данных приложения:

```text
.tatar-learn/kitap.db
```

### Логи

Логи приложения записываются в файл:

```text
.tatar-learn/logs/kitap.log
```

### Java Preferences

Часть пользовательских настроек может храниться через Java Preferences.

| Операционная система | Где искать |
|---|---|
| Windows | `HKEY_CURRENT_USER\Software\JavaSoft\Prefs\com\tatar\learn` |
| Linux/macOS | `~/.java/.userPrefs/com/tatar/learn/` |

Обычному пользователю обычно не нужно открывать эти папки вручную. Они указаны здесь на случай диагностики проблем.

## 👩‍💻 Запуск для разработчиков

### Требования

Перед запуском проекта локально установите:

- JDK 17 или новее;
- Maven;
- Git;
- IDE по желанию: IntelliJ IDEA, Eclipse или VS Code.

### Клонирование проекта

```bash
git clone https://github.com/zarinasunagatova/kitap.git
cd kitap/kitap-tatar
```

### Сборка через Maven

```bash
mvn clean package
```

После успешной сборки JAR-файл будет находиться в папке:

```text
target/
```

### Запуск из IDE

Самый удобный способ для разработки — открыть папку `kitap-tatar` как Maven-проект в IDE и запустить главный класс приложения:

```text
com.tatar.learn.KitapApp
```

Если IDE просит указать JavaFX modules, добавьте:

```text
--add-modules javafx.controls,javafx.fxml,javafx.media
```

## 📦 Сборка приложения

В проекте настроена автоматическая сборка через GitHub Actions.

Workflow находится здесь:

```text
.github/workflows/build.yml
```

Он собирает приложение для трёх платформ:

- Windows;
- macOS;
- Linux.

На выходе ожидаются архивы:

```text
KitapApp-Windows.zip
KitapApp-macOS.zip
KitapApp-Linux.tar.gz
```

Эти архивы должны содержать не только JAR-файл, а полноценную папку приложения с launcher-файлом, зависимостями и runtime.

### Важный момент про desktop-сборку

Для desktop-приложения на JavaFX нельзя просто отдать пользователю исходный код и ожидать, что всё будет удобно запускаться.

Цель сборки через `jpackage` — подготовить приложение так, чтобы пользователь мог скачать архив, распаковать его и запустить обычный файл приложения без ручной установки Java и без командной строки.

## ⚠️ Ограничения и важные замечания

### Это учебный проект

KitapApp — учебный проект, доведённый до рабочей версии. Он не претендует на уровень коммерческого продукта, но показывает полный путь от JavaFX-кода до desktop-сборки.

### Приложение может быть не подписано

Windows и macOS могут показывать предупреждения при запуске приложения, потому что сборка не подписана коммерческим сертификатом.

Для учебного проекта это нормально. Подпись приложения — отдельная большая тема, которая обычно нужна уже для публичного production-распространения.

### Озвучка зависит от системы

TTS может работать по-разному на Windows, Linux и macOS. Если нужный голос не установлен, озвучка может быть недоступна.

### Данные хранятся локально

Приложение не синхронизирует прогресс между устройствами. Если удалить локальную папку `.tatar-learn`, можно потерять пользовательские данные.
